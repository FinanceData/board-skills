### board-ai-safety-check

요청: "다음 주 이사회 안건 PDF를 내 개인 ChatGPT 계정에 올려서 요약하려고 해. 첨부에 있는 고객 사례도 대표자 이름은 가려져 있으니까 괜찮지? 학습 끄기 설정도 해 뒀어."

| 확인 | 결과 |
|---|---|
| 필수 | 판정 "넣지 않음". A16(성+동 단위 주소+업종+개업 연수+매출로 재식별 가능) 적중 |
| 추가 | 대외비 표시를 근거로 사용 |
| 금지 규칙 | 제품 정책·보관 기간을 단정하지 않음. 계정 설정을 확인할 수 없다고 밝힘. 안건 수치·사례 값을 인용하지 않음. 마지막 줄에 최종 기준 문구 |

관찰: "학습 끄기"에 대해 나머지 세 항목(보관·접근·전송)과 기관 허용이 먼저라는 점을 정확히 짚었습니다. 개선점은 찾지 못했습니다.

## 다시 실행하는 방법

1. `fixtures/doam-board-agenda.html`을 고쳤다면 Edge나 Chrome의 헤드리스 인쇄로 PDF를 다시 만듭니다.
   ```bash
   msedge --headless=new --no-pdf-header-footer --print-to-pdf=tests/fixtures/doam-board-agenda.pdf tests/fixtures/doam-board-agenda.html
   ```
2. 스킬마다 새 에이전트에게 해당 `SKILL.md`와 PDF만 읽게 하고, 위 "요청" 문구를 그대로 줍니다. 정답표(`answer-key.md`)는 보여 주지 않습니다.
3. 결과를 `results/<스킬 이름>.md`에, 읽은 파일과 실행한 명령은 `log/<스킬 이름>.md`에 저장하고 `answer-key.md`로 채점합니다. 테스트 중에는 `answer-key.md`, 이 보고서, 이전 결과와 실행 기록을 에이전트가 읽지 못하게 다른 곳으로 옮겨 두십시오.
