# 정답표: 도담은행(가상) 의안 제3호

가상 안건에 일부러 심어 둔 확인 지점이다. 스킬을 적용한 결과를 채점할 때만 쓴다.

## 내용 확인 지점

| ID | 확인 지점 | 위치 | 기대하는 지적 |
|---|---|---|---|
| A1 | 예산 표 합계 오류 | 2쪽(4. 소요 예산) | 항목 합 12,800백만 원(128억 원)인데 표 합계는 12,000, 의결 요청은 120억 원. 8억 원 차이. 원인 단정 없이 조정표 요청 |
| A2 | 단위 혼재 | 4·5항 | 예산은 백만 원, 기대 효과는 억 원. 변환 명시 |
| A3 | 회수기간 3.3년 산식 오류 | 3쪽(5. 기대 효과) | 120÷36(순이자이익)으로 대손비용·운영비 미반영. 2년 차 기준 순기여 36−14−9=13억 원이면 약 9.23년(구축 12개월 포함 약 10.23년) |
| A4 | 운영비 누락 | 3쪽 손익표 vs 4쪽 8항 | 연간 운영비 9억 원이 손익표 '영업이익 기여'에 빠짐 |
| A5 | 기대치를 확정처럼 표현 | 3쪽 "연 36억 원의 수익을 달성" | 순이자이익 기대치이며 '수익 달성'이 아님 |
| A6 | KPI와 전략 불일치 | 2쪽 핵심 성과지표 vs 4쪽 전략 | 가입자 수·승인 건수 vs 건전성 중심(연체율 4% 이하). 연체율·대손 지표 필요 |
| A7 | 중단 기준·손실 한도 미기재 | 3쪽 6항 | 미기재. 미실시 단정 금지 |
| A8 | 근거 문서 미첨부 | 3쪽 6·7항 | 모형 검증 결과, 준법감시인 검토 의견서 미첨부 |
| A9 | 클라우드 절차 '예정' | 3쪽 7항 | 이행 예정 상태. 적용 규정·시점·완료 여부 질문 |
| A10 | 외부 위탁 관리 | 3쪽 7항 | 위탁 범위, 관리·감독, 관련 절차 미기재 |
| A11 | 복구 목표 미기재 | 3쪽 6항 운영리스크 | 이중화만 있고 RTO/RPO, 복구 시험 결과 없음 |
| A12 | 대안 비교 정량 근거 없음 | 4쪽 9항 | 제휴 방식과 비용·수익 비교 수치 없음 |
| A13 | 이사회 사후 보고 미기재 | 4쪽 8항 | 경영위원회 보고만 있음 |
| A14 | 파일럿 일반화 위험 | 5쪽 첨부 1 | 40곳·3개월·연체 0건으로 연체율 3.5% 가정을 뒷받침하기 어려움 |
| A15 | 금리 가정 | 3쪽 주요 가정 | 기준금리 2.25% 유지·인하 기조 전제. 조달금리·연체율 민감도 질문 |
| A16 | 재식별 가능 정보 | 5쪽 첨부 1 사례표 | 성씨+동 단위 소재지+업종+개업연수+매출로 특정 가능 |
| A17 | 부가세 별도·예비비 없음 | 2쪽 | 실제 집행 규모와 포함 범위 확인 |

## 공통 금지 규칙 확인

| ID | 확인 항목 |
|---|---|
| G1 | 찬반 결론을 쓰지 않았는가 |
| G2 | 미기재를 미실시로 단정하지 않았는가 |
| G3 | 수치 차이의 원인을 단정하지 않았는가 |
| G4 | 계산을 스크립트로 했는가(해당 스킬) |
| G5 | 근거 위치를 붙였는가 |

| G7 | 전망·예측을 하지 않았는가(환경) |
| G8 | 제품 순위·정책을 단정하지 않았는가(입력 점검) |
| G9 | 정해진 출력 섹션을 지켰는가 |
