# 사외이사 AI 강의 진행 도우미

금융연수원 사외이사 과정(120분, 44장)을 진행하는 강사용 스킬이다. 안건을 직접 검토하려면 `board-agenda-review`를 쓴다.

장별 상세 노트(핵심 메시지, 말할 내용, 진행 팁, 주의)는 `references/lecture-notes.md`에 있다. 사용자가 특정 장이나 부분을 물으면 그 파일에서 해당 장을 찾아 답한다. 전체를 한꺼번에 읽어 주지 않는다. 장 번호는 교안의 쪽 번호와 같다.

## 청중과 목표

- 대면 8명, 비대면 4명(연수원 안내 기준, 접수 마감 전이라 바뀔 수 있음)
- 현업에 있지 않은 비상근 사외이사. 제한된 일정에 제한된 안건 정보만 가지고 이사회에 참석한다.
- 연령대가 있어 컬러 인쇄본을 함께 본다. 화면보다 인쇄본 쪽 번호로 안내하는 편이 편하다.
- 청중이 원하는 것: ① 받은 안건의 요약과 주요 질문거리, ② 금융 경영환경 변화에 대한 인사이트를 받고 정리하는 방법, ③ 내 전문성에 비추어 이사회에서 점검할 부분.
- 오늘 가져갈 결과물: **안건 검토 메모 1장, 우선 질문 5개, 추가 요청자료 3개.**

## 시간표

| 시간 | 과정 구성 | 진행 내용 | 장 |
|---|---|---|---|
| 0~25분 | AI의 이해와 변화 | AI 발전 흐름, 활용 5단계 | 1~15 |
| 25~40분 | AI 활용 인사이트 | 정보 입력 범위, 질문 설계 | 16~21 |
| 40~70분 | 의사결정 지원 활용 | 가상 이사회 안건 검토 | 22~31 |
| 70~95분 | 의사결정 지원 활용 | 전문성별 질문, 에이전트 시연 | 32~38 |
| 95~110분 | AI 활용 인사이트 | 금융환경 변화 읽기 | 39~41 |
| 110~120분 | 정리 | 정리, 질의응답 | 42~44 |

별도 휴식 시간은 없다. 휴식이 필요하면 5~14장의 도구 소개와 35장 시연 시간을 줄인다. 25분(15장)과 40분(21장) 시점에 진행을 점검하고, 늦어지면 16~19장을 짧게 진행한다.

## 강의 전 준비

- [ ] 실습 도구를 하나로 정하고 교수자 계정에서 미리 실행해 본다. 수강생에게 현장에서 설치나 가입을 시키지 않는다.
- [ ] 22~24장의 가상 안건과 30장 공통 프롬프트를 실습 도구에 미리 넣어 둔다. (가상 안건은 `board-agenda-review`의 `assets/sample-agenda.md`, 공통 프롬프트는 같은 스킬의 `references/prompt-template.md`)
- [ ] 사용할 도구의 데이터 정책(학습 활용, 보관 기간, 접근, 외부 전송)과 계정 설정 화면을 확인해 둔다. 18장에서 질문이 나온다.
- [ ] 39~41장에 쓸 공식 공개자료 2~3건을 고른다. 발표일과 통계 대상 기간을 함께 적어 둔다.
- [ ] 비대면 참석자에게 HTML 파일 또는 인쇄본의 쪽 번호 기준으로 진행한다고 안내한다.
- [ ] 연수원의 사전 설문 답변이 오면 16장에 추가한다.

## 진행의 기본 원칙

- 모든 사례와 수치가 가상 자료라는 점은 1장에서 한 번만 말한다.
- 교안의 버튼(투표, 판단 보기, 분류, 계산기, 탭, 시연 단계)은 미리 작성한 학습용 화면이다. 실제 AI 호출, 서버 전송, 응답 집계는 없다고 먼저 밝힌다.
- 특정 제품의 우열이나 국내 모든 계정의 이용 가능성을 말하지 않는다.
- "개인 계정에서 설정 하나만 끄면 이사회 자료를 다 넣어도 된다"고 말하지 않는다.
- 규정 사례는 절차 설명이며 특정 법률 해석이 아니다. 회수기간 계산은 NPV나 경제성 승인의 근거가 아니다.
- 금리 예시와 환경 변화 설명은 설명용 가정이다. 실제 전망이나 금융 자문이 아니다.

## 부분별 핵심

| 부 | 장 | 한 줄 요약 |
|---|---|---|
| 1부 AI의 이해와 변화 | 1~15 | 질문 → 생산 → 자동화 → 위임 → 운영. 오늘 직접 쓸 것은 1·2단계, 목표는 업무 자동화가 아니라 질문의 품질 |
| 2부 안전한 사용과 질문 설계 | 16~21 | 입력 여부는 사용권한·기관 정책·재식별 가능성으로 판단. "괜찮나요?" 대신 "무엇이 빠졌나요?" |
| 3부 가상 안건 검토 | 22~31 | 사실·가정·미기재 구분, 숫자는 직접 더하기, AI의 지적도 원문 대조 |
| 4부 전문성별 질문 | 32~38 | 질문 = 확인할 주장 + 판단 기준 + 필요한 증빙. 질문 5개와 요청자료 3개를 짝짓기 |
| 5부 금융환경 변화 읽기 | 39~41 | 변화 → 영향 경로 → 반대 시나리오 → 질문 |
| 6부 정리와 질의응답 | 42~44 | 근거, 구분, 행동. 맡길 범위와 확인 기준은 사람이 정한다 |

## 예상 질문과 답변

**Q. 회사 안건을 ChatGPT에 넣어도 됩니까?**
회사가 허용한 서비스와 계정인지가 먼저다. 개인 계정이라면 미공개 안건은 넣지 않는 것이 원칙이다. 공개된 자료나 안건에서 숫자와 이름을 뺀 구조만 넣어 질문 틀을 만드는 방법은 있다. (17~18장)

**Q. "학습에 사용 안 함"을 켜면 안전합니까?**
학습은 네 가지 중 하나일 뿐이다. 보관 기간, 접근 권한, 외부 전송도 따로 확인해야 한다. (18장)

**Q. 어떤 AI가 제일 좋습니까?**
순위보다 작업과 허용 범위로 고른다. 19장의 다섯 질문을 쓴다. 한 가지만 꾸준히 써서 익숙해지는 것이 여러 개를 오가는 것보다 낫다.

**Q. AI가 틀린 내용을 그럴듯하게 쓰면 어떻게 압니까?**
근거 위치(쪽수, 원문 문장)를 꼭 요구하고, 숫자는 직접 확인한다. "자료에 없으면 확인 필요로 표시하라"는 문장을 프롬프트에 넣는다. (21, 26, 30장)

**Q. AI가 정리한 질문을 그대로 이사회에서 써도 됩니까?**
초안으로 쓰되 원문과 대조하고 중요도는 직접 정한다. 질문의 책임은 이사에게 있다. (36~37장)

**Q. 회사가 AI를 도입한다고 하면 이사로서 무엇을 물어야 합니까?**
AI가 접근하는 정보의 범위, 오류를 발견하는 절차, 승인과 중단의 기준, 책임 주체를 묻는다. (15장)

**Q. 에이전틱 AI는 꼭 여러 AI가 있어야 하나요?**
아니다. 업계에서는 단일 에이전트가 계획, 행동, 피드백으로 일을 진행하는 방식에도 이 말을 쓴다. 강의에서는 이해를 돕기 위해 비서와 조직으로 나눴을 뿐 용어는 기관마다 쓰는 범위가 다르다. (9장)
