# 계산 예시 (가상 A은행 디지털 신규사업)

모든 수치는 교육용 가상 자료다. 실제 투자나 의결 판단에 쓰지 않는다.

## 입력

- 승인 요청액(투자금): 150억 원
- 연간 기대 총편익: 45억 원
- 출시 후 연간 운영비: 12억 원
- 구축 기간: 18개월
- 세부 예산: 개발 90 / 시스템 연계 35 / 인프라 25 / 교육·전환 15

## 세부 예산 합계

90 + 35 + 25 + 15 = **165억 원**. 승인 요청액 150억 원과 **15억 원 차이**.

원인은 계산 오류일 수도, 중복 항목일 수도, 별도 예산일 수도 있어 자료만으로는 알 수 없다. 부가세, 예비비, 포함 범위도 함께 묻는다.

## 회수기간 정답표

| 조건 | 계산 | 결과 |
|---|---|---|
| 기본 (실현율 100%, 운영비 12억) | 150 ÷ (45 − 12) | 출시 후 약 4.55년 |
| 구축 18개월 포함 | 4.55 + 1.5 | 약 6.05년 |
| 운영비를 빠뜨린 잘못된 계산 | 150 ÷ 45 | 3.33년 |
| 실현율 60%, 운영비 12억 | 150 ÷ (27 − 12) | 순편익 15억, 출시 후 10년 |
| 순편익 0 이하 | | 회수가 성립하지 않음 |

실현율을 100%에서 60%로 내리면 회수기간이 두 배 이상이 된다. 그다음 운영비를 올려 보면 더 크게 달라진다.

## 한계

할인, 세금, 편익이 늘어나는 과정, 투자 지출 시점을 반영하지 않은 단순 민감도 예시다. 전액 선투자하고 구축 중에는 편익이 없다고 가정했다. 세부 예산 165억 원과의 차이는 먼저 조정해야 한다.
