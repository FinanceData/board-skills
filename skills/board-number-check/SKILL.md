# 안건 숫자 점검

안건의 합계, 비율, 회수기간을 **스크립트로** 계산하고, 결과를 이사회 질문으로 바꾼다. 다른 board 스킬도 계산이 필요하면 이 스킬의 스크립트를 쓴다.

## 실행 절차

1. **쪽수 기준을 밝혀라.** 근거 위치에 쓰는 쪽수가 PDF 쪽인지 문서에 인쇄된 쪽 번호인지 출력 첫머리에 한 줄로 적어라.
2. **입력값 표를 만들어라.** `항목 / 값 / 단위 / 근거 위치` 열로 계산에 쓸 숫자를 모두 적어라.
3. **단위를 확인하라.** 억 원과 백만 원이 섞여 있으면 "단위 변환: 1,500백만 원 → 15억 원"처럼 변환 사실을 적어라. 원래 단위로 계산하려면 `--unit "백만 원"`을 붙여라.
4. **합계를 대조하라.** 경로는 이 스킬 폴더 기준이다.
   ```bash
   python scripts/check_numbers.py sum --requested <요청액> <항목>=<값> <항목>=<값> ...
   ```
   승인 요청액이 아닌 값(표에 적힌 소계, 영업이익 기여 등)과 대조할 때는 `--label "표 기재 합계"`처럼 기준값 이름을 바꿔라. 빼야 하는 항목은 음수로 넣어라(예: `대손비용=-14`).
5. **비율을 대조하라.** 안건에 비율(승인율, 연체율, 비중 등)이 있으면 실행하라.
   ```bash
   python scripts/check_numbers.py ratio <분자> <분모> --stated <안건 기재 %>
   ```
   두 값의 차이만 필요하면(안건 가정 금리와 현행 금리, 대출금리와 조달금리, 누적 이익과 투자금 등) `sum` 대신 `diff`를 써라. 단위가 `%`면 차이는 `%p`로 나온다.
   ```bash
   python scripts/check_numbers.py diff <기준값> <비교값> --unit % --base-label "안건 가정" --value-label "현행"
   ```
   `sum`은 "합계가 기준값과 맞는가"를 볼 때만 써라. `sum`의 원인 단정 금지 문구는 대조용이다.
6. **회수기간을 계산하라.** 투자금과 연간 편익이 있으면 실행하라.
   ```bash
   python scripts/check_numbers.py payback --investment <투자금> --benefit <연간 총편익> --opex <연간 운영비> --credit-cost <연간 대손비용> --build-months <구축 개월>
   ```
   - `--benefit`에는 운영비·대손비용을 빼기 **전**의 총편익(예: 순이자이익)을 넣어라. 이미 비용을 뺀 값(예: 영업이익 기여)을 넣고 같은 비용을 또 빼지 마라.
   - 특정 실현율을 물으면 `--realization 60`을 붙여라(0.6도 된다). 실현율은 스크립트가 **총편익에만** 적용하고 운영비·대손비용은 그대로 둔다.
7. **출력을 그대로 옮겨라.** 숫자를 고치거나 다시 반올림하지 마라.
8. **해석을 한 문장으로 써라.** 기대치와 계산 결과가 어떻게 다른지만 써라.
9. **질문으로 바꿔라.** 결과마다 이사회에서 물을 질문을 하나 이상 붙여라.
10. **한계를 붙여라.** 회수기간을 출력했으면 "할인·세금·편익 증가 과정·투자 지출 시점을 반영하지 않은 단순 민감도"라고 반드시 적어라.

## 금지 규칙

- **암산하지 마라.** 합계, 차이, 비율, 회수기간은 스크립트 출력만 쓴다.
- **스크립트 출력을 수정하지 마라.**
- **차이의 원인을 단정하지 마라.** "계산 오류입니다", "중복 계상입니다"는 금지다.
- **회수기간으로 사업성을 결론짓지 마라.** "회수기간이 길어 사업성이 없습니다"는 금지다.
- **NPV·IRR 결과처럼 표현하지 마라.** 이 계산은 할인율을 쓰지 않는다.
- **비용을 두 번 빼지 마라.** 이미 대손비용을 뺀 이익에 `--credit-cost`를 또 넣지 마라.
- **이미지에서 읽기 어려운 숫자를 추정하지 마라.**
- **계산 결과로 찬반을 권하지 마라.**

## 예외 처리

- 안건의 산식이 그대로 재현되더라도 그 산식이 운영비·대손비용 같은 안건 속 다른 비용을 빼먹었다면: 답의 **첫 문장**에 "안건 산식으로는 재현되지만 ○○을 반영하지 않은 값"이라고 함께 써라. "맞습니다"만으로 시작하지 마라.
- Python을 실행할 수 없는 환경이면: 계산식을 단계별로 적고 결과 옆에 `검산 필요`를 표시하라. 사용자에게 계산기로 확인해 달라고 요청하라.
- 운영비가 안건에 없으면: `--opex 0`으로 계산하되 "운영비 미기재로 0 가정. 실제 회수기간은 더 길 수 있음"을 결과 바로 옆에 적어라.
- 순편익이 0 이하이면: 스크립트가 출력하는 "회수가 성립하지 않음"을 그대로 쓰고, 운영비와 편익 산식을 묻는 질문으로 연결하라.
- 세부 합계와 요청액이 다르면: 회수기간은 요청액 기준으로 계산하고 "세부 합계와의 차이를 먼저 조정해야 함"을 덧붙여라.
- 구축 기간이 없으면: `--build-months`를 빼고 "출시 후 기준"이라고만 써라.

## 예시

### 예시 1. 합계 대조

입력:
> 세부 예산이 개발 90, 시스템 연계 35, 인프라 25, 교육·전환 15억 원이고 요청액은 150억 원이야. 맞아?

실행:
```bash
python scripts/check_numbers.py sum --requested 150 개발=90 시스템연계=35 인프라=25 교육전환=15
```

올바른 출력:
> 세부 합계는 165억 원으로 승인 요청액 150억 원보다 15억 원 큽니다(안건 1·2쪽). 원인은 자료만으로 알 수 없습니다.
> 질문: 승인 요청액과 세부 내역을 맞춘 조정표를 제시해 주십시오. 부가세·예비비 포함 여부도 함께 밝혀 주십시오.

잘못된 출력:
> 담당 부서가 15억 원을 잘못 더한 것으로 보입니다.

### 예시 2. 안건이 제시한 회수기간 확인

입력:
> 투자 120억, 2년 차 순이자이익 36억, 대손비용 14억, 운영비 9억, 구축 12개월. 안건엔 회수기간 3.3년이라는데 맞아?

실행:
```bash
python scripts/check_numbers.py payback --investment 120 --benefit 36 --opex 9 --credit-cost 14 --build-months 12
```

올바른 출력:
> 안건의 3.3년은 120억 원을 순이자이익 36억 원으로 나눈 값이라 대손비용 14억 원과 운영비 9억 원을 반영하지 않았습니다. 두 비용을 빼면 연간 순편익은 13억 원, 출시 후 약 9.23년(구축 포함 약 10.23년)입니다.
> 질문: 대손비용과 운영비를 반영한 연도별 현금흐름으로 회수기간을 다시 제시해 주십시오.
> 한계: 할인·세금·편익 증가 과정·투자 지출 시점을 반영하지 않은 단순 민감도입니다.

잘못된 출력:
> 네, 안건 산식대로라면 3.3년이 맞습니다.

### 예시 3. 비율 대조

입력:
> 65곳 중 40곳 승인, 승인율 61.5%라는데 맞아?

실행:
```bash
python scripts/check_numbers.py ratio 40 65 --stated 61.5
```

올바른 출력:
> 40 ÷ 65는 61.54%로 안건의 61.5%와 반올림 범위에서 일치합니다.

### 예시 4. 가정과 현행 값의 차이

입력:
> 안건은 기준금리 2.25%를 가정했는데 지금은 3.00%야. 차이가 얼마야?

실행:
```bash
python scripts/check_numbers.py diff 2.25 3.00 --unit % --base-label "안건 가정 기준금리" --value-label "현행 기준금리"
```

올바른 출력:
> 현행 기준금리가 안건 가정보다 0.75%p 높습니다.
> 질문: 현행 금리 수준에서 조달금리와 순이자이익 추정을 다시 산출해 주십시오.

## 자유도

| 반드시 매뉴얼대로 | 판단해도 되는 영역 |
|---|---|
| 계산은 스크립트로만 | 강조할 민감도 시나리오 선택 |
| 입력값 표와 근거 위치, 쪽수 기준 표시 | 추가 시나리오 설계(예: 운영비 20% 증가). 단, 계산은 스크립트로 |
| `--benefit`에는 비용 차감 전 총편익 | `--unit`, `--label`로 원래 단위·이름 유지 여부 |
| 출력 수치를 고치지 않음 | 질문 문장의 표현 |
| 한계 문구 포함 | 결과를 표로 보일지 문장으로 보일지 |
| 금지 규칙 전부 | 해석 문장의 어조 |

## 테스트 예시 파일

아래 파일은 **테스트 예시**다. 스크립트가 제대로 동작하는지 확인할 때 쓰고, 그 안의 가상 수치를 실제 안건 결과로 옮겨 쓰지 마라.

- `scripts/check_numbers.py` (테스트 예시 포함): 계산 스크립트. 파일 머리의 사용 예 수치는 가상 A은행 사례다
- `references/worked-example.md` (테스트 예시): 가상 사례의 정답표. 스크립트 출력이 이 값과 다르면 입력이나 스크립트를 점검하라
