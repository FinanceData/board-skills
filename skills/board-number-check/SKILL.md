# 안건 숫자 점검

안건의 합계와 회수기간을 **스크립트로** 계산하고, 결과를 이사회 질문으로 바꾼다.

## 실행 절차

1. **입력값 표를 먼저 만들어라.** `항목 / 값 / 단위 / 근거 위치` 열로 계산에 쓸 숫자를 모두 적어라.
2. **단위를 통일하라.** 억 원과 백만 원이 섞여 있으면 하나로 바꾸고 "단위 변환: 1,500백만 원 → 15억 원"처럼 변환 사실을 적어라.
3. **합계를 대조하라.** 다음 명령을 실행하라. 경로는 이 스킬 폴더 기준이다.
   ```bash
   python scripts/check_numbers.py sum --requested <요청액> <항목>=<값> <항목>=<값> ...
   ```
4. **회수기간을 계산하라.** 투자금과 연간 편익이 있으면 실행하라.
   ```bash
   python scripts/check_numbers.py payback --investment <투자금> --benefit <연간 총편익> --opex <연간 운영비> --build-months <구축 개월>
   ```
   특정 실현율을 물으면 `--realization 60`을 붙여라(0.6도 된다).
5. **출력을 그대로 옮겨라.** 숫자를 고치거나 다시 반올림하지 마라.
6. **해석을 한 문장으로 써라.** 기대치와 계산 결과가 어떻게 다른지만 써라.
7. **질문으로 바꿔라.** 결과마다 이사회에서 물을 질문을 하나 이상 붙여라.
8. **한계를 붙여라.** 회수기간을 출력했으면 "할인·세금·편익 증가 과정·투자 지출 시점을 반영하지 않은 단순 민감도"라고 반드시 적어라.

## 금지 규칙

- **암산하지 마라.** 합계, 차이, 비율, 회수기간은 스크립트 출력만 쓴다.
- **스크립트 출력을 수정하지 마라.**
- **차이의 원인을 단정하지 마라.** "계산 오류입니다", "중복 계상입니다"는 금지다.
- **회수기간으로 사업성을 결론짓지 마라.** "회수기간이 길어 사업성이 없습니다"는 금지다.
- **NPV·IRR 결과처럼 표현하지 마라.** 이 계산은 할인율을 쓰지 않는다.
- **이미지에서 읽기 어려운 숫자를 추정하지 마라.**
- **계산 결과로 찬반을 권하지 마라.**

## 예외 처리

- Python을 실행할 수 없는 환경이면: 계산식을 단계별로 적고 결과 옆에 `검산 필요`를 표시하라. 사용자에게 계산기로 확인해 달라고 요청하라.
- 운영비가 안건에 없으면: `--opex 0`으로 계산하되 "운영비 미기재로 0 가정. 실제 회수기간은 더 길 수 있음"을 결과 바로 옆에 적어라.
- 순편익이 0 이하이면: 스크립트가 출력하는 "회수가 성립하지 않음"을 그대로 쓰고, 운영비와 편익 산식을 묻는 질문으로 연결하라.
- 세부 합계와 요청액이 다르면: 회수기간은 요청액 기준으로 계산하고 "세부 합계와의 차이를 먼저 조정해야 함"을 덧붙여라.
- 구축 기간이 없으면: `--build-months`를 빼고 "출시 후 기준"이라고만 써라.

## 예시

### 예시 1. 합계 대조

입력:
> 세부 예산이 개발 90, 시스템 연계 35, 인프라 25, 교육·전환 15억 원이고 요청액은 150억 원이야. 맞아?

실행:
```bash
python scripts/check_numbers.py sum --requested 150 개발=90 시스템연계=35 인프라=25 교육전환=15
```

올바른 출력:
> 세부 합계는 165억 원으로 승인 요청액 150억 원보다 15억 원 큽니다(안건 1·2쪽). 원인은 자료만으로 알 수 없습니다.
> 질문: 승인 요청액과 세부 내역을 맞춘 조정표를 제시해 주십시오. 부가세·예비비 포함 여부도 함께 밝혀 주십시오.

잘못된 출력:
> 담당 부서가 15억 원을 잘못 더한 것으로 보입니다.

### 예시 2. 실현율 민감도

입력:
> 편익이 60%만 나오면 회수기간은? 투자 150, 편익 45, 운영비 12억이야.

실행:
```bash
python scripts/check_numbers.py payback --investment 150 --benefit 45 --opex 12 --realization 60 --no-sensitivity
```

올바른 출력:
> 실현율 60%면 연간 순편익은 15억 원, 출시 후 회수기간은 약 10.00년입니다(실현율 100%일 때 약 4.55년).
> 질문: 편익 45억 원의 산식과 연도별 실현 시점, 실현율 60% 시나리오의 현금흐름을 제시해 주십시오.
> 한계: 할인·세금·편익 증가 과정·투자 지출 시점을 반영하지 않은 단순 민감도입니다.

## 자유도

| 반드시 매뉴얼대로 | 판단해도 되는 영역 |
|---|---|
| 계산은 스크립트로만 | 강조할 민감도 시나리오 선택 |
| 입력값 표와 근거 위치 | 추가 시나리오 설계(예: 운영비 20% 증가). 단, 계산은 스크립트로 |
| 출력 수치를 고치지 않음 | 질문 문장의 표현 |
| 한계 문구 포함 | 해석 문장의 어조 |
| 금지 규칙 전부 | 결과를 표로 보일지 문장으로 보일지 |
