# 안건 검토 메모 양식

검토 메모는 안건의 결론이 아니라 추가 확인을 위한 구조다. 아래 양식을 채우되, 안건에 없는 항목은 비우지 말고 `미기재` 또는 `확인 필요`로 쓴다.

```markdown
# 안건 검토 메모

- 안건명:
- 검토 대상 자료: (안건 N쪽, 수치표, 전략 요약 등 받은 자료 목록)
- 검토자 전문분야: (재무·회계 / 법률·준법 / 리스크 / IT·보안)
- 작성 기준: 제공된 자료만 사용. 받지 못한 자료는 7항에 표시.

## 1. 의결 요청 요약
| 항목 | 내용 | 근거 위치 |
|---|---|---|
| 의결 요청 | | |
| 명시된 조건 (기간, 금액, 기대 효과, 운영비) | | |
| 책임자·보고체계 | | |

## 2. 사실·가정·미기재
| 문장 | 분류 | 이유 | 근거 위치 |
|---|---|---|---|
| | 문서상 사실 / 성과 가정 / 미기재 | | |

## 3. 수치 확인
| 항목 | 안건 수치 | 직접 계산한 값 | 차이 | 비고 |
|---|---|---|---|---|

차이의 원인은 단정하지 않고 "조정표 요청"으로 연결한다.

## 4. 전략 연결
| 회사 전략 | 안건에 적힌 것 | 추가로 물을 것 |
|---|---|---|

## 5. 우선 질문 5개
| # | 주제 | 질문 | 근거 위치 | 중요도 |
|---|---|---|---|---|
| 1 | 승인 범위 | | | |
| 2 | 편익 근거 | | | |
| 3 | 대안 비교 | | | |
| 4 | 위험·중단 | | | |
| 5 | 책임·보고 | | | |

## 6. 추가 요청자료 3개
| # | 자료 | 답하는 질문 | 담당 부문 |
|---|---|---|---|
| 1 | | | |
| 2 | | | |
| 3 | | | |

## 7. 확인 필요 및 한계
- 받지 못한 자료:
- 확정하지 못한 항목:
- 이 메모는 초안이며 원문 대조와 질문의 중요도 판단은 이사가 한다.
```

## 작성 예 (가상 A은행 사례)

| 항목 | 내용 |
|---|---|
| 의결 요청 | 디지털 신규사업 추진 및 150억 원 승인 |
| 명시된 조건 | 구축 18개월, 기대 총편익 45억 원, 운영비 12억 원 |
| 수치 확인 | 세부 예산 합계 165억 원, 요청액과 15억 원 차이 |
| 핵심 불확실성 | 편익 산식, 실현 시점, 대안 비교, 중단 기준 |
| 다음 행동 | 예산 범위 조정, 현금흐름과 위험관리 자료 요청 |

실습 결과와 비교하는 예시이며 유일한 정답이 아니다. 예산 차이를 발견해도 원인까지 단정하지 않는다.
