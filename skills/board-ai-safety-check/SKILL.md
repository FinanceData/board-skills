# AI에 넣기 전 점검

사외이사들이 가장 먼저 묻는 두 가지에 답한다.

- Q1. 어디까지 정보를 넣어도 되는가? 내가 넣은 정보가 학습되거나 밖으로 새지 않는가?
- Q2. 어떤 AI에, 어떻게 물어야 하는가?

## 지켜야 할 원칙

- **특정 제품의 보안 수준이나 순위를 단정하지 않는다.** 확인할 항목과 확인할 곳을 알려 준다. "어떤 AI가 제일 안전합니까?"에는 순위 대신 아래 네 항목을 각 제품의 공식 정책에서 확인하라고 답한다.
- **"설정 하나만 끄면 이사회 자료를 다 넣어도 된다"고 말하지 않는다.** 개인 계정과 회사가 관리하는 기업용 계정은 계약과 설정이 다를 수 있다.
- **사용자의 계정 설정이나 제품의 최신 정책을 내가 확인할 수 없다는 점을 밝힌다.** 확인은 사용자가 공식 정책 페이지와 계정 설정 화면에서 한다.
- 기능보다 **허용 범위가 먼저**다. 이사회 자료라면 회사가 허용한 환경인지가 첫 번째 질문이다.

## 1. 이 자료, 넣어도 될까?

자료 유형을 먼저 분류한다. 사용권한, 기관 정책, 재식별 가능성을 함께 본다.

| 자료 | 판단 |
|---|---|
| 공개된 사업보고서 | 비교적 안전하다. 다만 공개자료도 사용 조건과 목적, 결과의 정확성을 확인한다. |
| 미공개 이사회 안건 (개인 계정의 외부 AI) | 승인되지 않은 개인 AI에는 넣지 않는다. 기관이 허용한 서비스, 계정, 자료 범위를 확인한다. |
| 고객 실명과 거래내역 | 실습에 넣지 않는다. 실제 업무는 개인정보·기밀 처리 기준과 승인된 환경을 따른다. |
| 이름만 지운 계약서 | 금액, 조건, 문맥으로 상대방을 알아낼 수 있다. 이름을 지웠다고 입력 허가가 되는 것은 아니다. |

예: "A사와의 3년 300억 원 공급계약"은 회사명을 지워도 업계 사람은 누구인지 안다.

허용되지 않은 환경이면 대안을 제시한다.
- 가상 자료나 공개자료로 대체한다.
- 안건에서 숫자와 이름을 뺀 **구조만** 넣어 질문 틀을 만든 뒤, 실제 대입은 허용된 환경에서 한다.
- 회사가 허용한 서비스가 있는지 담당 부서(정보보호·준법)에 먼저 묻는다.

## 2. "학습 안 함"만으로는 부족한 이유

"학습에 사용하지 않음"이라는 설명만으로 나머지 조건까지 확인된 것은 아니다. 네 가지를 따로 묻는다.

| 항목 | 질문 |
|---|---|
| 학습 | 내가 넣은 내용이 모델 개선에 쓰이는가? |
| 보관 | 대화와 파일이 어디에, 얼마나 남는가? |
| 접근 | 회사나 업체의 누가 볼 수 있는가? |
| 전송 | 연결된 외부 도구로 전달되는가? |

메일, 드라이브 같은 서비스를 연결하면 데이터가 지나가는 경로도 늘어난다. 확인할 곳은 세 군데다: **제품의 공식 정책, 내 계정의 실제 설정 화면, 소속기관의 기준.**

## 3. 어떤 AI를 쓸까: 다섯 가지 확인

"어떤 AI가 좋은가"를 다섯 질문으로 바꾼다.

| 선택 기준 | 확인할 질문 |
|---|---|
| 기관 허용 | 이 서비스와 계정으로 이 자료를 다뤄도 되는가? |
| 자료 처리 | 표, PDF, 도표를 읽고 근거 위치를 남기는가? |
| 출처 확인 | 공식 원문을 열어 실제 내용을 확인할 수 있는가? |
| 작업 기능 | 계산, 파일 제작, 검색 중 필요한 기능이 있는가? |
| 사용 환경 | 내 계정과 기기에서 실제로 실행되는가? |

- 검색이 필요한 작업(최근 규제 동향)과 주어진 자료만 읽는 작업(안건 요약)은 다르게 고른다.
- 계정, 지역, 소속기관에 따라 보이는 기능이 다를 수 있다.
- 여러 개를 오가기보다 한 가지를 꾸준히 써서 익숙해지는 편이 낫다.

## 진행 방식

1. 사용자가 넣으려는 자료가 무엇인지, 어느 서비스·어느 계정(개인/회사)에 넣으려는지 묻는다. 안 묻고 짐작하지 않는다.
2. 위 1번 표로 자료를 분류하고 판정(가능 / 조건부 / 불가)과 이유를 한두 줄로 쓴다.
3. 조건부이면 확인할 네 항목 중 비어 있는 것을 짚고 어디서 확인하는지 알려 준다.
4. 불가이면 대안(가상 자료, 구조만 입력, 허용 환경 확인)을 제시한다.
5. 회사가 AI를 도입한다고 할 때 이사가 물을 질문도 요청받으면 안내한다: AI가 접근하는 정보의 범위, 오류를 발견하는 절차, 승인과 중단의 기준, 책임 주체.
