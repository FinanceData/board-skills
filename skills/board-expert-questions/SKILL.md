# 전문분야별 질문과 다관점 검토

"내 전문성에 비추어 이사회에서 점검해야 할 부분"을 질문과 요청자료로 바꾼다. 안건 전체의 검토 메모는 `board-agenda-review`, 이 스킬은 그 위에서 전문분야 관점을 더한다.

## 지켜야 할 원칙

- 질문은 **확인할 주장 + 판단 기준 + 필요한 증빙**으로 쓴다. "사업성이 있습니까?" 같은 넓은 질문으로 끝내지 않는다.
- 질문마다 **그 질문에 답하는 요청자료**를 짝지어 쓴다. 자료를 많이 요청하는 것이 목표가 아니다.
- 질문은 제공된 안건에 근거해 만든다. 안건에 없는 사실을 전제로 하지 않고, 근거 위치를 붙인다.
- 위원회나 보고체계는 회사마다 다르므로 임의로 가정하지 않는다.
- 질문의 책임은 이사에게 있다. 만든 질문은 초안이며 원문과 대조하고 중요도는 이사가 정한다.

## 1. 전문분야별 질문 만들기

사용자의 분야를 먼저 확인한다(복수 가능). 분야별 질문 예시와 요청자료는 `references/perspectives.md`에 있다. 그것을 그대로 복사하지 말고 **현재 안건의 수치와 문구에 맞게** 바꿔 쓴다.

기본 요청 형식: "나는 [분야] 전문가인 사외이사다. 이 안건에서 내 전문성으로 이사회에서 점검해야 할 부분 3가지와 각각의 질문, 필요한 자료를 정리한다."

출력은 점검 부분 3가지, 각각의 질문, 필요한 자료 표로 한다. 자기 분야 외에 **옆 분야 질문도 하나** 골라 덧붙이면 시야가 넓어진다고 안내한다.

## 2. 질문 좁히기

사용자가 쓴 질문을 받으면 위 형식으로 바꿔 준다.

| 넓은 질문 | 구체적인 질문 |
|---|---|
| "사업성이 있습니까?" | "편익 실현율 60%에서도 손익 기여 목표를 달성합니까? 연도별 현금흐름을 제시해 주세요." |
| "리스크 관리는 잘 되고 있습니까?" | "출시 첫해 이용자가 목표의 절반일 때 손실 한도는 얼마이며, 누가 축소를 결정합니까?" |

## 3. 여러 관점의 검토를 하나의 질문 목록으로

구조는 다음과 같다.

1. **조정**: 범위, 자료, 검토 기준을 정한다.
2. **관점별 검토**: 재무(예산, 편익, 현금흐름), 리스크(실패 시나리오, 중단 기준), 준법(원문, 적용 조건, 증빙)이 따로 검토한다.
3. **통합**: 중복을 지우고 의견 불일치와 근거를 확인한다.
4. **사람이 확인**: 원문, 수치, 누락을 확인하고 우선 질문을 선택한다.

반드시 밝혀야 할 점:
- 한 대화에서 역할만 바꿔 묻는 것은 **다관점 검토**이지 별도 에이전트의 독립 실행이 아니다. 그렇게 했다면 그렇게 표시한다.
- 여러 관점이 같은 결론을 냈다고 독립적으로 검증된 것은 아니다. 같은 자료와 비슷한 모델이면 같은 오류가 함께 나타날 수 있다.
- 관점의 수가 많다고 검토가 타당해지는 것은 아니다.

### 검토 결과가 다를 때

다수결로 정하지 않는다. 가정과 근거가 어디서 다른지 본다. 흐름은 아래와 같다.

| 단계 | 내용 |
|---|---|
| 1. 자료 확인 | 공통 수치를 확인한다. 예: 요청액과 세부 합계의 차이 |
| 2. 역할별 검토 | 재무는 회수 가능성, 리스크는 실현 불확실성, 준법은 기준과 증빙에 주목 |
| 3. 불일치 확인 | 총편익과 순편익, 손익 기여와 투자금 회수, 미기재와 미실시를 구분 |
| 4. 질문 통합 | 예산 조정과 현금흐름, 실현율 하락 시 손실과 중단 기준, 적용 기준과 검토 근거를 요청 |

최종 질문 목록은 중요도 순으로 5개 이내로 줄이고, 각 질문에 요청자료를 짝지어 준다.
